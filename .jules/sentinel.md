## 2026-09-24 - [XSS in inline event handlers]
 **Vulnerability:** Unescaped single quotes in inline event handler (`onclick="toggleGroup(this, ' + escHtml(id) + ')"`) inside a dynamically generated HTML string.
 **Learning:** `encodeURIComponent` does not encode single quotes. If the resulting string is used within an inline event handler wrapped in single quotes, an attacker can break out of the string context and execute arbitrary JavaScript. Escaping single quotes in `escHtml` as `&#39;` is insufficient for inline event handlers, because the browser decodes HTML entities before executing the JavaScript handler. So `toggleGroup(this, '&#39;-alert(1)-&#39;')` becomes `toggleGroup(this, ''-alert(1)-'')` which executes `alert(1)`.
 **Prevention:** Ensure single quotes are safely encoded. In JavaScript, use `.replace(/'/g, '%27')` after `encodeURIComponent`, or replace single quotes with `\\x27` if escaping specifically for JS string context. Always escape single quotes in general HTML escape functions like `escHtml` (`&#39;`) to prevent attribute injection.
